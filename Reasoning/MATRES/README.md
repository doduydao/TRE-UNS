# MATRES

This folder contains output, logs, and analysis artifacts for the MATRES dataset in the `Reasoning` branch.

## Structure

```text
MATRES/
├── analysis/              # Violation, repair, and comparison analysis
├── checkpoint/            # Trained model checkpoints
├── log_*.txt              # Train / evaluate / predict logs
├── prediction*.csv        # Predictions from each run
└── doc_pair_counts_*.csv   # Document pair counts
```

## Installation

There is no separate installation for this folder. Follow the root [README](../../README.md) and [Reasoning/README.md](../README.md).

## Usage

Run from the `Reasoning/` directory:

```bash
bash script/run.sh MATRES train
bash script/run.sh MATRES evaluate
```

## Notes

- This is an output folder, not source code.
- The CSV and log files here can be regenerated by the `tre_reasoner/` pipeline and `script/run.sh`.
