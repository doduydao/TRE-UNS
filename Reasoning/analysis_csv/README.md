# analysis_csv

This folder contains CSVs and analysis images generated from reasoning runs.

## Structure

```text
analysis_csv/
├── *.csv
├── *.png
└── README.md
```

## Installation

No separate installation is needed. This is output generated by the analysis pipeline.

## Notes

- Files here are usually generated by scripts in `Reasoning/debug_model/` or by notebooks.
- They can be regenerated by rerunning the experiment and the corresponding analysis scripts.
