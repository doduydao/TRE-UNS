# TBD

This folder contains output, logs, and analysis artifacts for the TBD dataset in the `Reasoning` branch.

## Structure

```text
TBD/
├── analysis/              # Violation, trajectory, and case-study analysis
├── checkpoint/            # Trained model checkpoints
├── log_*.txt              # Train / evaluate / predict logs
├── prediction*.csv        # Predictions from each run
└── doc_pair_counts_*.csv   # If generated by the pipeline
```

## Installation

There is no separate installation for this folder. Follow the root [README](../../README.md) and [Reasoning/README.md](../README.md).

## Usage

Run from the `Reasoning/` directory:

```bash
bash script/run.sh TBD train
bash script/run.sh TBD evaluate
```

## Notes

- `analysis/` usually contains files for case studies and trajectory reasoning.
- `log_*.txt` and `prediction*.csv` are outputs generated by the train/evaluate pipeline.
