# notebook

This folder contains experiment notebooks and helper files for data/model exploration.

## Structure

```text
notebook/
├── *.ipynb
├── data.py
└── README.md
```

## Installation

In addition to the `Reasoning/tre_reasoner` environment, install Jupyter if you want to open the notebooks:

```bash
pip install jupyterlab ipykernel
```

## Notes

- The notebooks here are mainly for experimentation and manual analysis.
- `data.py` is usually a shared helper for the notebooks.
